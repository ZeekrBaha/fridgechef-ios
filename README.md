# FridgeChef

iOS app that turns a list of ingredients (typed as chips or photographed) into
3 recipe suggestions via GPT-4o Vision.

- Swift + UIKit + Combine, MVVM
- iOS 17+, no third-party deps, Core Data for recipe history
- OpenAI key injected at build time from `~/Desktop/llm-ai-projects/youtube_pdf_reporter/.env`
